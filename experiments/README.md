# Experiments

아직 일반화되지 않은 방법을 실제 자료로 검증하는 공간입니다.

각 실험에는 최소한 다음을 남깁니다.

- 질문 또는 가설
- 사용한 자료와 조건
- 수행 방법
- 관찰된 결과와 한계
- 다음 판단: 중단, 반복, pattern/facet 후보

한 번 성공한 예시를 곧바로 원칙으로 승격하지 않습니다. 다른 문맥에서도 재현되거나 명확한 운영상 이점이 확인되면 [`okf/`](../okf/index.md)의 관련 개념이나 [facet](../facets/README.md)에 반영합니다.

[적용 피드백](../okf/feedback.md)은 비교하거나 재현할 가설의 출발점이 될 수 있습니다. 제보된 결과와 실험으로 확인한 결과를 구분하고, 확인된 조건과 한계를 관련 개념 및 적용 자료에 반영합니다.

## 진행 중인 실험

- [Personal context](personal-context/README.md) - Knowledge-centered 관점과 Mekra의 운영 원칙이 개인 맥락을 충분히 설명하는지 최소 구조에서 검증한다.
