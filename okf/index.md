# Mekra Method의 운영 지식

Mekra Method가 채택한 원칙의 상세 의미·근거·경계와 운영 패턴·적용 판단을 찾는 색인이다. 원칙의 목록·핵심·상호 관계는 [운영 원칙](../PRINCIPLES.md), 실제 적용 흐름은 [적용 안내](../APPLICATION.md)에서 시작한다. 이곳의 지식은 현재 OKF로 표현하며, [OKF의 형식과 활용](okf-format.md)과 Mekra의 운영 선택을 구분한다. OKF로 표현된 지식이라고 해서 그 판단 근거의 효력이 형식 설명에만 한정되는 것은 아니다.

## 질문에서 시작하기

| 판단할 질문 | 먼저 읽을 지식과 연결 |
| --- | --- |
| 지금 무엇을 구축하거나 바꾸고 어디까지 완료할까? | [적용 판단](adoption.md)에서 현재 상태와 범위를 정하고, [구축 방향의 협의](construction-consultation.md)에서 미확정 운영 방향을 다룬다 |
| 어떤 지식 단위와 설명 깊이가 충분할까? | [설계 탐색과 충분성](knowledge-design.md)에서 대안을 비교하고, [지식 내재화](knowledge-internalization.md)에서 개념의 경계와 보존할 맥락을 판단한다 |
| 지식은 어디에 두고 여러 Mekra를 어떻게 찾을까? | [구조와 발견](structure-and-discovery.md)에서 번들·운영 범위·진입점을 구분한다 |
| 만든 지식을 실제로 사용하고 이후 갱신하려면 무엇이 필요할까? | [실제 사용과 운영 인계](knowledge-operation.md)에서 사용 환경·자료 투입·갱신 방법을 연결한다 |
| 원자료나 판단이 바뀌면 무엇을 함께 고칠까? | [정본과 맥락](source-of-truth.md)에서 변경 책임을 확인하고, [맥락 파급](context-propagation.md)과 [인식적 차이](epistemic-distinctions.md)를 함께 살핀다 |
| 자료가 많을 때 무엇을 내재화하고 무엇을 참조할까? | [대량 자료](large-corpus.md)와 [원자료·파생물](external-sources.md)에서 판단의 중요성·근거·유지 비용을 구분한다 |
| 실제 도움이 됐는지, 무엇을 방법론에 되돌릴까? | [적용 경험의 환류](feedback.md)에서 관찰·해석·효과의 근거를 구분한다 |
| 어떤 내용을 공개하고 배포판의 의미를 어떻게 맞출까? | [공개 경계](disclosure-boundary.md)와 [배포 동기화](distribution.md)를 함께 읽는다 |

아래 목록은 전체 개념을 찾는 경로다. 질문별 경로는 출발점이며 읽을 범위를 고정하지 않는다.

## 운영 철학

- [자율 판단](agent-autonomy.md) - 에이전트의 자율 판단을 출발점으로 삼고, 목적과 맥락에 맞게 다른 운영 원칙의 적용을 이끈다.
- [인식적 차이의 보존](epistemic-distinctions.md) - 자료와 사용자의 주장·관점·불확실성에서 판단에 의미가 있는 차이를 보존한다.
- [운영 원칙](../PRINCIPLES.md) - 자율 판단을 바탕으로 정본과 맥락을 유지하고 구조·지침의 필요를 다시 판단한다.
- [자기소거](self-erasure.md) - 판단에 필요한 만큼 돕고, 필요가 줄어드는 만큼 지침과 방법론의 역할을 덜어낸다.
- [지식 내재화](knowledge-internalization.md) - 새로운 지식의 의미와 영향을 관련 개념에 반영한다.
- [지식 설계의 탐색과 충분성](knowledge-design.md) - 구성 대안과 탐색 범위를 실제 사용·변경에 비추어 비교하고 선택한다.
- [주문 지식의 구성 비교 예시](knowledge-design-example.md) - 같은 규칙을 담은 OKF 본문으로 질문·변경·설계 이유의 인계를 비교한다.

## 재사용 패턴과 경계

- [정본과 맥락](source-of-truth.md) - 변경 책임을 단일화하면서 필요한 재서술을 유지한다.
- [맥락 파급](context-propagation.md) - 의미가 달라지는 개념을 함께 갱신한다.
- [원자료와 파생물](external-sources.md) - 원자료·파생물·내재화된 지식의 책임을 나눈다.
- [정보 접근과 외부 공개의 경계](disclosure-boundary.md) - 내부 판단에 사용할 수 있는 정보와 외부 공개·전송 권한을 구분한다.
- [대량 자료의 지식 구성](large-corpus.md) - 핵심 지식과 요약·탐색 경로를 조합한다.
- [Facet의 역할과 경계](facet-boundaries.md) - facet을 대상의 성질을 읽는 얇은 관점으로 사용하고 preset이나 중복 지식 계층으로 만들지 않는다.

## 형식과 실제 적용

- [OKF의 역할과 활용](okf-format.md) - 표현 방식과 번들 경계를 이해하고 공식 형식과 운영 선택을 구분한다.

- [적용 판단](adoption.md) - 현재 상태와 필요한 변화, 이번 완료 범위를 판단하고 적용의 전체 맥락을 연결한다.
- [구축 방향의 협의와 위임](construction-consultation.md) - 실제 자료에 근거한 잠정 설계로 운영 방향을 정하고 세부 판단을 위임한다.
- [Mekra의 구조와 발견](structure-and-discovery.md) - 번들·논리적 운영 범위·진입점·발견 인덱스의 책임을 구분한다.
- [지식의 실제 사용과 운영 인계](knowledge-operation.md) - 사용 연결을 확인하고 이후 자료 투입과 갱신을 이어갈 맥락을 남긴다.
- [적용 경험의 환류](feedback.md) - 재사용할 관찰을 선별해 연구와 운영 지식의 개선으로 연결한다.
- [연구와 다국어 배포의 동기화](distribution.md) - 공개 범위와 공통 지식의 정본을 유지하며 언어별 배포판을 갱신한다.
- [적용 안내](../APPLICATION.md) - 대상 탐색부터 문답, 반영과 완료 후 사용 안내까지의 기본 경로.
- [Facet](../facets/README.md) - 대상의 중요한 성질에서 관련 판단을 찾는 얇은 관점.
- [템플릿](../templates/README.md) - 복사해서 조정하는 출발점.
